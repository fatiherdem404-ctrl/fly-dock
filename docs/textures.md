# Raf dokuları

Ahşap, açık ahşap, ceviz, mermer, siyah mermer, fırçalı metal, beton ve tuğla raflarının resimleri

Hepsi **CC0 1.0 (kamu malı)** lisanslıdır: ticari kullanım ve dağıtım serbest, atıf zorunlu değil.
Uygulamada 1024 px JPEG'e çevrilmiş renk (Color) haritaları kullanılır (`src/assets/desk/`).
